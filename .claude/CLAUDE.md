## Proyecto
Sistema de gestión financiera. Diseño, arquitectura e implementación de módulos financieros.

## Stack
Node.js / Next.js / React / TypeScript

## Comandos
- npm run dev — iniciar servidor dev
- npm run build — build producción
- npm start — iniciar servidor prod
- npm run lint — ESLint

- Estructura de líderes / Gestión territorial
- Análisis político
- Prospección estadística
- Políticas y documentos normativos
